# EventManagement

EventManagement is a college fest management web portal that helps organize and manage events efficiently. Students can register, view, and participate in events, while admins can create, edit, and manage them.

## Features

- Students can register and browse the list of events
- Students can sign up and take part in events
- Admins can create, edit, and manage events

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: JSP, Servlets
- Database: MySQL

## Project Files

- `index.html` - main page of the portal
- `style.css` - styling
- `script.js` - client-side logic

## Getting Started

1. Clone the repository
2. Set up the MySQL database and update the connection details
3. Deploy the project on a servlet container such as Apache Tomcat
4. Open the portal in your browser
